# Cursussen — WordPress Course Management Plugin

> **Supporting portfolio project · WordPress/PHP · custom post types · REST API · shortcodes · responsive UI**

Cursussen is a WordPress plugin for managing course information and publishing it through a responsive shortcode or public REST API. It demonstrates a focused content model, safe public data exposure and maintainable WordPress functionality without unnecessary dependencies.

**Developer profile:** [Andrew Baeten](https://github.com/Yolol100) · [Portfolio cases](https://andrewbaeten.nl/category/cases)

## What it demonstrates

| Area | Implementation |
| --- | --- |
| WordPress | Custom post type, taxonomy, settings and lifecycle handling |
| Front end | Responsive course overview and accessible accordion behaviour |
| REST API | Paginated public endpoints limited to published course data |
| Performance | Bounded queries and dependency-light frontend JavaScript |
| Safety | Sanitized settings, scoped assets and controlled uninstall behaviour |

## Requirements

- WordPress 6.3+
- PHP 7.4+
